# Prototype Application

The application is built only after the experimental configuration is frozen.

Minimum interface:

- user question and detected language;
- concise answer;
- canonical exact citation;
- quoted supporting evidence;
- source document and version;
- retrieval/escalation path;
- verified, uncertain, or abstained state;
- explicit human-review warning.

The application must not expose raw API keys, hidden prompts, or unverified confidence claims. It is a research decision-support prototype, not an autonomous compliance decision-maker.
