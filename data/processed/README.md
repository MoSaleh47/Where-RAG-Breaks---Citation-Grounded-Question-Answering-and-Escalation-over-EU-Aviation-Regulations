# Processed Corpus

Only validated, schema-conforming parent/child corpora belong here.

Promotion from `interim/` requires:

- deterministic unique IDs;
- regulation and document-type separation;
- hierarchy-path validation;
- citation normalization;
- parent/child referential integrity;
- table-header preservation;
- character/token count checks;
- manual review of a stratified sample;
- a validation report with zero unexplained critical errors.
