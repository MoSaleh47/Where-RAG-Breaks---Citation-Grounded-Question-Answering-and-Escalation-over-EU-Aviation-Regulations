\chapter{Generative AI Use Disclosure}
\label{app:ai-disclosure}

Generative AI tools were used in this PFE and are disclosed in accordance with the aivancity guidelines.

\section{Research-System Use}

A hosted language model was used in the historical project to generate synthetic question-answer records and to produce outputs for stored baseline systems. The benchmark audit therefore treats the evaluation set as synthetic and records model-family coupling as a validity limitation.

Hosted embedding models were used after explicit authorisation to encode public regulatory retrieval text and candidate questions. Model-specific vectors, input hashes, and token counts were cached. The local cross-encoder reranker did not transmit project questions or passages to a hosted inference service.

\section{Development and Writing Assistance}

OpenAI Codex was used as an AI-assisted development and research tool for repository inspection, test and script implementation, experiment-manifest checking, document structuring, LaTeX conversion, and drafting support. AI-produced code and prose remain subject to student review. Methodological decisions, interpretation, legal accuracy, source selection, and final conclusions must be understood, checked, and approved by the student.

No AI system is treated as an independent reviewer of benchmark corrections it proposed. The 33-row evidence-review package explicitly requires a separate human reviewer or transparent uncertainty marking.

\section{Verification and Responsibility}

The final report will distinguish primary-source facts, computed experiment outputs, candidate interpretations, and unresolved draft text. Bibliographic claims will be checked against primary publications. Regulatory statements will be checked against the stored official source material. The student remains responsible for every submitted claim, citation, code excerpt, and conclusion.
